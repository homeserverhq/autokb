What is AutoKB?

AutoKB is a distributed, event-driven ETL orchestration engine. It connects to diverse data sources via a drop-in plugin system; each plugin pulls data, transforms it, and writes chunks (markdown, JSON, or text) to a per-subscription output directory. Downstream knowledge base importers consume those files.

How to use an existing plugin

  1. Open Data Sources in the sidebar. Each tile is a registered plugin.
  2. Click a plugin tile to see its subscriptions, then click + Create New Subscription.
  3. Fill in the required fields (like connection details or URLs) and save.

How to create your own plugin

  1. Open Developer Lab in the sidebar.
  2. Below the code editor you'll find the Plugin Development Guide — a complete walkthrough for building a plugin. You can copy it and use it as a skill prompt for an AI coding assistant.
  3. Write or paste your plugin code in the editor, give it a name, and optionally upload a .png icon (max 512×512).
  4. Click Test to check for errors, then Save to deploy. Your plugin appears in Data Sources within seconds.
