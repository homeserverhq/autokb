What is AutoKB?

AutoKB is a distributed, event-driven ETL orchestration engine. On the upstream side, it connects to diverse data sources via drop-in Source connectors; each Source pulls data, transforms it, and writes chunks (markdown, JSON, or text) to a per-subscription output directory. On the downstream side, Destination connectors (sinks) receive those files and sync them to remote knowledge bases / datasets (Data Targets).

How to use an existing Source

  1. Open Data Sources in the sidebar. Each tile is a registered Source connector.
  2. Click a Source tile to see its subscriptions, then click + Create New Subscription.
  3. Fill in the required fields (like connection details or URLs) and save.

How to create your own Source

  1. Open Developer Lab in the sidebar and pick Source Developer.
  2. Below the code editor you'll find the Plugin Development Guide — a complete walkthrough for building a Source connector (plugin). You can copy it and use it as a skill prompt for an AI coding assistant.
  3. Write or paste your plugin code in the editor, give it a name, and optionally upload a .png icon (max 512×512).
  4. Click Test to check for errors, then Save to deploy. Your Source appears in Data Sources within seconds.
